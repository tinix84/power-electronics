Converter tolerances: analytical sensitivity and Monte Carlo

Student exercise · Averaged continuous-conduction models

Engineering question

Do identical parasitic components cause identical gain errors in buck, boost, and inverting buck-boost converters? Predict which converter is most sensitive before you calculate the results. Then test your prediction with symbolic differentiation and random sampling.

The comparison holds input voltage, load resistance, and duty cycle fixed within each case. Output voltage, output power, and inductor current differ between converters. This is a comparison of gain degradation, not an equal-power hardware selection.

Assume steady state, continuous conduction mode (CCM), and small inductor-current ripple. Use a constant diode drop and constant resistances at a fixed temperature. Ignore switching losses, capacitor ESR, core losses, reverse recovery, and self-heating. The duty cycle does not change to regulate output voltage.

For a CCM plausibility check, use mH and switching frequency kHz. Assume a sufficiently large output capacitor for negligible voltage ripple. These values establish a teaching operating regime, not a checked magnetic-component design.

Part C — Run paired Monte Carlo calculations

Monte Carlo analysis repeatedly evaluates a model with randomly sampled inputs. Here, each sample represents one possible component set within the assumed tolerances. It does not represent a switching cycle or a time trace.

  1. Generate the three independent uniform parameter arrays.
  2. Evaluate the original nonlinear gain and the Taylor approximation for each sample.
  3. Compare the analytical standard deviation with both sampled standard deviations.
  4. Compare the sample means, medians, and fifth and ninety-fifth percentiles.
  5. Repeat with half and quarter tolerance widths, keeping the same normalized random samples.
  6. Calculate the root-mean-square difference between paired nonlinear and linearized gains.

Require the sampled linear standard deviation to agree with the analytical value within 1%. Require its mean to lie within five analytical standard errors of the nominal gain. Use the tolerance-scaling experiment to assess Taylor error separately from Monte Carlo sampling error.

Do not require exact equality between nonlinear and linearized results. Explain any systematic mean shift and any asymmetric distribution.
