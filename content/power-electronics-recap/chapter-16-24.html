16.24 Can a 200 Ω differential input look like 2 MΩ to the source?

Predict. Use §11.6's voltage-amplifier two-port with Rdiff = 200 Ω, DC open-loop gain A₀ = 100,000 and zero output resistance. There are initially no input-to-ground leakage paths, bias currents or capacitances. Compare a non-inverting gain-of-ten connection and a conventional inverting gain-of-minus-nine connection, retaining the finite 200 Ω in both calculations. These are authored model values, not specifications for a real op amp.

A. Non-inverting: the − input follows the + input

Drive + with Vin. Connect Rf = 9 kΩ from output to − and Rg = 1 kΩ from − to reference. The unloaded feedback divider has β = 0.1 and Thévenin resistance Rt = Rf ∥ Rg = 900 Ω. Let Iin flow from + through Rdiff into the feedback node. Then:

At DC, Zin = 2.0011 MΩ and voltage gain is 9.9945. With 100 mV input, output is about 0.99945 V, but the differential input voltage is only 9.9945 µV. The current through the 200 Ω resistor is therefore only 49.97 nA. The resistor has not changed: feedback makes both its terminals move almost together.

Using Miller's resistive form, the ratio v−/v+ is approximately 0.9999001, so Rdiff/[1 − (v−/v+)] gives the same 2.0011 MΩ. As A tends to infinity in this specified linear model, the differential voltage and input current tend to zero while the source-facing impedance tends to infinity. It is the open-loop voltage gain that is very large; the feedback-set signal gain remains near ten.

Do not silently neglect divider loading. Since 900 Ω is not small relative to 200 Ω, the usual unloaded-divider shortcut is not exact. The actual loop gain in this model is Aβ/(1 + Rt/Rdiff). The impedance can also be written (Rdiff + Rt) times one plus that loop gain. This retains the same mechanism while accounting for the loading.

Sweep the open-loop gain from 100 to one million: approach both ideal ports. For this additional DC calculation, change the internal output resistance from zero to 100 Ω so that the effect of feedback on the output can be seen. Keep Rdiff = 200 Ω, Rf = 9 kΩ and Rg = 1 kΩ.

There is no external output load; the feedback divider remains connected. Vary only A₀. This is a separate finite-output-resistance model, so its input values differ slightly from the zero-output-resistance calculation above.

Both are approaching the ideal voltage-amplifier behaviour: no current drawn from the signal source, and little output-voltage change when load current changes. They do not both grow toward infinity. The closed-loop voltage gain approaches ten, rather than growing to one million.

To measure output resistance, set the ideal input voltage source to zero (short it to reference), keep the controlled source and feedback active, inject a small current at the output and calculate ΔVout/ΔItest. Do not deactivate the dependent amplifier source. Here Rg ∥ Rdiff = 166.67 Ω, and the output's passive return through the divider is M = Rf + (Rg ∥ Rdiff) = 9166.67 Ω.

The loaded feedback fraction is 1/55. Including the 100 Ω internal output resistance gives the DC loop gain L₀ = 0.0179856 A₀, and improvement factor F = 1 + L₀.

For L₀ ≫ 1, input resistance is approximately proportional to A₀ and output resistance approximately inversely proportional to A₀. The proportionality is not exact at low loop gain: A₀ = 100 gives L₀ only about 1.80, explaining the substantial gain error in the first row.

In the ideal A₀ → infinity limit of this circuit, Rin → infinity and Rout → zero. Real leakage, input capacitance, finite bandwidth, output current limits and interconnection impedance constrain that limit. TI's Handbook of Operational Amplifier Applications likewise explains the reduction of output impedance by negative feedback.

C. Does this make the transistor input resistance irrelevant?

No: it separates feedback action from intrinsic device properties. First, a real current path from the signal input to reference bypasses differential bootstrapping. Adding an illustrative 1 MΩ input-to-ground shunt puts it in parallel with 2.0011 MΩ, reducing external input impedance to 666.8 kΩ. Bias currents, common-mode leakage and input capacitance are not removed just because the differential voltage is small.

Second, loop gain falls with frequency. Let A(s) = 100,000/[1 + s/(2π × 10 Hz)], a one-pole open-loop model with approximately 1 MHz unity-gain frequency. The low 200 Ω resistance loads the feedback divider, producing a non-inverting closed-loop corner of 18.19 kHz. Changing only Rdiff to 10 MΩ moves that corner to about 100.0 kHz.

Their DC gains are both near ten, but their bandwidths differ substantially. At frequencies where A approaches zero, the non-inverting model's source-facing impedance approaches Rdiff + Rt = 1.1 kΩ, not 2 MΩ.

Change one thing: reduce open-loop gain, change only Rdiff, or add an input-to-ground shunt. Predict separately the differential voltage, source current and closed-loop bandwidth. Do not assume v+ = v− first and then use that assumption as proof that input current is zero; obtain the small error from the finite-gain equations.

The effect also requires a stable negative-feedback loop operating within its linear input/output range. Analog Devices' discussion of differential input capacitance explains why real differential and common-mode input loading must be distinguished.

Topology choice. Use the non-inverting connection when positive gain near ten and low source loading are required. Feedback gives about 2 MΩ input impedance in this model. The cost is relying on adequate loop gain over the signal band.

Choose the inverting connection when inversion or summing is required, accepting current through its input resistor. Its gain of −9 is a different signal requirement; high input impedance alone cannot make the two circuits interchangeable.
