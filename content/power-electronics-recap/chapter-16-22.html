16.22 Two LC filters: why does multiplying their measured gains give the wrong answer?

Predict. Two second-order LC low-pass sections each have a −40 dB/decade high-frequency asymptote. If connected directly in cascade, can their individually measured voltage gains simply be multiplied? Does swapping their order matter?

Use a series inductor followed by a shunt capacitor for each stage, common return and no mutual magnetic coupling:

Vs -- Zs -- (R1 + L1) --o-- (R2 + L2) --o-- Vout
                       |               |
                       C1             C2 || RL
                       |               |
                    common return / voltage reference

The connection is a cascade, not a parallel connection of two complete two-ports. With the ABCD convention of §11.4, a series impedance and shunt admittance have:

Tseries = [ 1   Z ]       Tshunt = [ 1   0 ]
          [ 0   1 ]                [ Y   1 ]

TLC = Tseries Tshunt = [ 1 + ZY   Z ]
                      [    Y     1 ]
Z = R + sL; Y = sC; s = j omega for frequency response.

Multiply the transmission matrices to obtain the full cascade, then calculate loaded Vout/Vs with the actual source and final load. This multiplication is valid and includes loading. Multiplying Z matrices, multiplying S matrices directly, or multiplying scalar gains measured with different terminations does not implement the same connection.

A. Find the loading factor before calculating every matrix entry

Let H₁,oc be stage 1's open-output gain from Vs, including its actual source impedance. Let H₂ be stage 2's input-voltage-to-output-voltage gain with the final load attached. Define Zout,1 with stage 1's source deactivated, and Zin,2 with stage 2's final load present. Thévenin gives:

If |Zout,1| is much smaller than |Zin,2|, the interface factor approaches one. If the second stage has very low input impedance compared with the first stage's output impedance, it nearly shorts the first stage's output and changes the response substantially. The comparison uses complex frequency-dependent impedances; around resonance the sum can also become small and produce peaking.

Low output impedance of the first stage is generally helpful, not the mechanism that shorts the next stage.

An ideal unity-gain unilateral buffer isolates the stages, making the product of these separately defined gains valid. A real buffer has bandwidth, impedance and power limits. No buffer is included in the passive cascade below.

The same interface in Z parameters. Let Za and Zb describe the first and second two-ports, respectively. Eliminating their shared-port voltage and opposite internal port currents gives, where the denominator is nonzero:

Dint = Za22 + Zb11
Ztotal11 = Za11 - Za12 Za21 / Dint
Ztotal12 = Za12 Zb12 / Dint
Ztotal21 = Zb21 Za21 / Dint
Ztotal22 = Zb22 - Zb21 Zb12 / Dint

This explicitly exposes the first network's Z₂₂ and the second network's Z₁₁ in the interface calculation. These are open-circuit Z parameters; they are not automatically the actual terminated Zout and Zin used in the Thévenin expression. If Dint vanishes, use the original port equations or another valid representation rather than performing a singular elimination.

B. The fourth-order asymptote survives, but the poles can move far apart

For the lossless limiting circuit, take Zs = 0 and an open final load, with all four L/C values nonzero. Then:

The product of the two isolated open-output gains misses the s²L₁C₂ term. It therefore misses the interstage interaction, despite having the same fourth-order leading term. Both ordinary nondegenerate cascades ultimately reach −80 dB/decade in this model, not a fixed “80 dB attenuation.” The loading can instead split the poles so far apart that the observed band has a long region near −40 dB/decade.

Losses, finite terminations and real parasitics further change the observed response.

Choose two stages with the same isolated natural frequency, f₀ ≈ 50.33 kHz, but different impedance scales:

Stage L C Characteristic scale √(L/C)
High impedance 100 µH 100 nF 31.62 Ω
Low impedance 1 µH 10 µF 0.316 Ω

With common LC product τ², define ρ = L₁/L₂ = C₂/C₁. The lossless denominator is 1 + (2 + ρ)(sτ)² + (sτ)⁴. The two orders give:

Cascade order ρ Lossless, open-load natural frequencies
High impedance → low impedance 100 4.984 kHz and 508.3 kHz
Low impedance → high impedance 0.01 47.88 kHz and 52.91 kHz

These are undamped natural frequencies, not universal loaded −3 dB corners. The plots add a series winding resistance R = 0.1√(L/C) to each inductor and use Zs = 0, RL = 1 kΩ. With those explicit terminations, voltage gain at the original f₀ is −40.04 dB for high→low and +32.69 dB for low→high.

The positive gain is resonant voltage magnification, not creation of power. Even the low→high order can exhibit interstage loading around resonance; compare actual Zin/Zout rather than assuming the characteristic scale alone settles every frequency.

Change one thing: reverse the same components, add damping, or insert a buffer. Ask students to predict the interface current and pole movement before viewing the Bode plots. The problem is not that ABCD multiplication fails; it is that scalar voltage gains are conditional on their terminations.

D. What if the two filters really are connected in parallel?

If both input ports share the same input voltage and both output ports share the same output voltage, with the same reference conductor, then Ytotal = Y₁ + Y₂, where the Y descriptions exist. For two identical series-L/shunt-C sections, the equivalent circuit has L/2 and 2C (and half the identical series winding resistance).

It is still second order, with the same LC product and natural frequency, not a fourth-order cascade. Port conditions and final loading still determine damping and measured gain.

Connection choice. For these directly connected passive filters, use the loaded cascade calculation. Multiplying isolated voltage gains omits the interface current and moves the predicted poles.

A buffer can make separate voltage transfers useful, but adds an active stage with power, bandwidth and load limits. Retain the passive connection here and compare its two orders and damping. Choose a buffer only when the application permits those extra requirements.
