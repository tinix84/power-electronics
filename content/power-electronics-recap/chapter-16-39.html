Credit: the riddle and its three questions are Sam Ben-Yaakov's, from his video Ideal transformer riddle (11 September 2020). The answer, the netlist, the checks and the figure below are authored for this recap.

Predict. Sam Ben-Yaakov posed this riddle in a short video and withheld the answer. Every textbook model of a transformer ends in the symbol of an ideal transformer, behind the magnetizing inductance, the leakage inductances and the winding resistances. Answer three questions before reading on. What is the definition of an ideal transformer? What are its network equations? How can a circuit simulator model it exactly, not approximately?

Most first answers describe a physical device: perfect coupling, no resistance, infinite permeability. Those are properties of a limit, not a definition. The definition is shorter, and it contains no magnetism at all.

Definition: two algebraic constraints and nothing else

With the signs of §11.4, both port currents entering and n = N₁/N₂, an ideal transformer is the two-port defined by:

Both relations are algebraic and hold at every instant. Three consequences follow without any further assumption:

  • No energy. v₁i₁ + v₂i₂ = 0 at every instant, so the element neither stores nor dissipates. Power that enters port 1 leaves port 2 immediately.
  • No frequency. Nothing in the definition differentiates or integrates. The element transforms a DC voltage exactly as it transforms a 100 kHz sine. A physical transformer cannot, and that is the clearest sign that the ideal transformer is not a magnetic device.
  • Impedance scaling. A load Z_L at port 2 appears as Z_in = n² Z_L at port 1, for any complex Z_L.

Compare §2.5: a perfectly coupled pair with k = 1 and L₁ = n² L₂ is a different element. Its inductance matrix has rank one, so it imposes v₁ = n v₂ exactly, but it replaces the current constraint by a state:

A k = 1 pair is therefore an ideal transformer with a magnetizing inductance L₁ across its primary. The ideal transformer is the limit L₁ → ∞ at fixed L₁/L₂, and the limit is where the energy state disappears.

Network equations: which matrices exist

Section 16.21 showed why the ideal transformer has no finite Z and no finite Y. Z needs I₁ and I₂ as independent variables, and n I₁ + I₂ = 0 forbids that. Y needs V₁ and V₂ independent, and V₁ − n V₂ = 0 forbids that. The representations that do exist are the ones whose independent variables the definition allows:

ABCD (with -I2):  [ V1 ]   [ n    0  ] [  V2 ]        det = 1
                  [ I1 ] = [ 0   1/n ] [ -I2 ]

Hybrid H:         [ V1 ]   [ 0    n ] [ I1 ]           V1 = n V2
                  [ I2 ] = [ -n   0 ] [ V2 ]           I2 = -n I1

Inverse hybrid G: [ I1 ]   [  0   -1/n ] [ V1 ]        G = inv(H)
                  [ V2 ] = [ 1/n    0  ] [ I2 ]

S, 50 ohm references, n = 2:  [ 0.6   0.8 ]            real, symmetric, S^T S = Id
                               [ 0.8  -0.6 ]

The hybrid matrix is the one to remember. Its two rows are the two defining equations written with mixed variables: a voltage controlled by a voltage and a current controlled by a current. That is exactly the vocabulary of a circuit simulator.

An exact SPICE model: two controlled sources

A simulator offers four controlled sources. The H rows name two of them: a voltage-controlled voltage source (E) for V₂ = V₁/n and a current-controlled current source (F) for I₁ = −I₂/n. The F source needs a current to sense, so a 0 V source sits in series with the E source:

* Ideal transformer, n = N1/N2. Primary p-0, secondary s-0.
E1   s   x   p   0   {1/n}      ; V(s,x) = V(p,0) / n
Vs   x   0   0                  ; 0 V sense: I(Vs) is the current entering at s
F1   p   0   Vs  {-1/n}         ; current -I(Vs)/n flows from p into F1

The sign deserves one line. SPICE counts I(Vs) positive from the + node x through the source to the − node. The current that enters the secondary at s flows through E1 into x and then through Vs, so I(Vs) = i₂ with the entering convention. F1 with a positive gain would draw g·I(Vs) out of node p into the source, which is the port current i₁ entering from outside; i₁ = −i₂/n fixes the gain at −1/n. The two sources exchange no energy with the rest of the circuit: E1 delivers exactly the power that F1 absorbs.

Every row satisfies V₁ = n V₂ and n I₁ = −I₂ to machine precision, including at DC. The model is exact because its equations are the definition. Two popular alternatives are approximations: a coupled pair with K = 1 and a large inductance leaves the magnetizing current of the previous subsection in the primary, and a pair with K slightly below one adds leakage. Both also need a DC path at every node, which the controlled-source model does not create by itself; the secondary reference s-0 above is that path.

How far a finite pair is from the ideal element

Load the secondary with R_L = 8 Ω and compare the k = 1 pair with the ideal element for three primary inductances. The magnetizing current is invisible in the voltage ratio and visible in the current ratio and the input impedance, which equals jωL₁ ∥ n² R_L:

k = 1, L₁ Corner ωL₁ = n² R_L |I₁| / |I₂/n| at 100 kHz |Z_in| at 100 kHz Step time constant L₁ / (n² R_L)
10 µH 509 kHz 5.19 6.2 Ω 0.31 µs
100 µH 50.9 kHz 1.12 28.5 Ω 3.1 µs
1 mH 5.09 kHz 1.001 32.0 Ω 31 µs

The step response says the same thing in time. A 10 V step on the primary gives a 5 V step on the ideal secondary that lasts forever. On the 100 µH pair the 5 V decays with τ = 3.1 µs, because the magnetizing current ramps until the primary source carries it all. Coupling below one works at the other end of the spectrum. With L₁ = 100 µH the open-circuit ratio falls to k/n and the short-circuit primary inductance L₁(1 − k²) rolls the loaded ratio off: 3 dB down at 2.5 MHz for k = 0.99 and at 217 kHz for k = 0.9. A real transformer is an ideal transformer bracketed by these two corners, which is why the engineer's T-model keeps the symbol in the middle.

Change one thing: set n = 1 and ask what the element still does; replace the 8 Ω load by a capacitor and check that Z_in is n² times that capacitor's impedance, not a different capacitor; drive the ideal element with a DC source and no load and ask why the simulator is happy while the laboratory transformer would saturate; swap the gain of F1 to +1/n and find which conservation law the netlist now violates.

Recall questions: Which two equations define the element, and which words in the usual description (coupling, permeability, resistance) are absent from them? Why does V₁ = n V₂ survive for a k = 1 pair while n I₁ = −I₂ does not? Which matrix has the defining equations as its rows, and which two SPICE primitives are those rows? Why does a coupled pair with K = 1 and a large inductance approximate but never equal the ideal element? Finally, what would the 0 V source Vs be for if the simulator could sense the current of E1 directly?

Representation choice. Define an element by its constraints, then ask which independent variables those constraints leave free; that choice fixes which matrix exists. For the ideal transformer, ABCD serves cascades, S serves matched measurements, and H serves the simulator. The engineer's T-model of §2.6 is the ideal element plus the two states that the definition removed. When a result needs the magnetizing current or the leakage corner, use that model; when it needs only the ratio, the two controlled sources are the honest and exact choice.
