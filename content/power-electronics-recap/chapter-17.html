17. Engineering approximation: how simple can the model be?

A model can reproduce many details and still answer the wrong question. A simpler model can support a decision if its errors remain acceptable.

This chapter develops the model-limit warning in Section 1.1. It is a separate methods chapter, outside the two-session refresher route. Its examples are authored teaching cases, not measured hardware results.

17.1 Start with the decision and an error budget

Suppose a calculation predicts a 0.40 V output drop against a 0.42 V limit. A neglected 0.04 V term changes the decision. Calling that term small does not make the design acceptable.

An approximation is useful when it preserves the conclusion within a stated error budget. Its value depends on the question, operating range and available margin. It is not a property of an equation alone.

Before calculating, answer these questions:

  1. Name the quantity that affects the decision.
  2. State its operating range.
  3. Set an acceptable absolute or relative error.
  4. List the effects that the model neglects.
  5. Identify a measurement or fuller calculation that can challenge the result.

Relative error is unsuitable when the reference value is zero. Use an absolute limit there. The reference calculation also has assumptions. Agreement with it does not validate the physical hardware.

The engineering skill is choosing which detail could change the decision. A larger model costs time, parameters and interpretation. Add detail when its expected effect competes with the error budget.

17.2 Use ratios, dimensions and limiting cases

Compare terms with compatible units. A resistance is not small by itself. Its ratio to another relevant impedance may be small.

Useful ratios include , , and propagation delay divided by edge time. Each ratio identifies a particular mechanism. None is a universal accuracy certificate.

  1. Check the dimensions of the proposed result.
  2. Calculate the controlling dimensionless ratio.
  3. Test a limiting case with an obvious physical answer.
  4. Restore the omitted term.
  5. Check whether the decision changes.

For a voltage divider, an open load should recover the open-circuit voltage. A shorted load should give zero terminal voltage. An expression that fails either check needs correction before refinement.

Dimensional agreement is necessary but insufficient. Two incorrect expressions can have the same units. Limiting cases and independent conservation checks provide different evidence.

17.6 Example: switching frequency does not define the fastest time scale

A 0.20 m connection has a propagation speed of . Its one-way delay is 1 ns.

At 100 kHz, the switching period is 10 µs. The delay-to-period ratio is only 0.0001. That ratio alone makes the connection look unimportant.

For a 2 ns edge, the delay-to-edge ratio is 0.5. For a 100 ns edge, it is 0.01. The fast-edge case deserves a distributed-line check despite the same switching frequency.

These ratios screen the time scales. They do not bound reflection error by themselves. Line impedance, termination, edge amplitude and the allowed disturbance also matter.

Use the lumped model when propagation effects stay within the required accuracy. Use a transmission-line model when travel time and reflections affect the observed edge.

17.7 Distinguish approximation error from uncertain inputs

An exact solution with an unknown capacitance is not an exact prediction of the hardware. Separate three questions:

Question Useful check
Did we solve the stated model correctly? Independent equations, integration or conservation checks.
Does omitted physics affect the decision? Restore the effect and compare against the error budget.
Are the input values credible? Datasheet conditions, tolerance limits and measurements.

Vary uncertain parameters over justified ranges. Keep worst-case bounds separate from a nominal prediction. Do not assume that several errors cancel without evidence.

A simulation can challenge a hand calculation. It cannot validate an effect that both models omit. Add a measurement that observes the mechanism under the stated conditions.

Practice. Revisit one converter calculation from a later lesson.

  1. Identify its simplest useful model.
  2. Name one neglected effect.
  3. Estimate that effect with units.
  4. Compare it with the available margin.
  5. State the condition that would change your model choice.

17.8 Reading and provenance

The examples and numbers above are original. The reading route supplies methods and model cautions, rather than borrowed circuit designs.

  • Sanjoy Mahajan, The Art of Approximation in Science and Engineering, MIT. Follow its dimensional reasoning, limiting cases and successive refinement.
  • Mahajan, Street-Fighting Mathematics, MIT Press. The publisher describes tools for educated estimates. This is further reading, not a claim that the complete book was reviewed here.
  • Agarwal and Lang, Foundations of Analog and Digital Electronic Circuits, MIT reading map. Start with lumped abstraction and linear equivalent circuits.
  • John Ardizzoni, Analog Devices: datasheets and SPICE macromodels. Check which device behavior a model actually includes.
  • Jim Williams, AN47, High Speed Amplifier Techniques. Use its high-speed measurement and construction discussions when checking neglected connection effects.

The chapter uses these as distinct reading references. It does not attribute a universal approximation rule to any author.
