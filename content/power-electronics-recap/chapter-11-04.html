11.4 Two-port recall: Z, Y, transmission and scattering matrices

A two-port network (quadripole) has a voltage and current at each port; it is not a two-terminal dipole. Use RMS phasors, both port currents entering the network and port voltages measured from their stated reference terminals. These signs must be fixed before converting matrices.

Representation Equations Useful connection / interpretation
Impedance Z V₁ = Z₁₁I₁ + Z₁₂I₂; V₂ = Z₂₁I₁ + Z₂₂I₂ Open-circuit parameter measurements; entries in Ω
Admittance Y I₁ = Y₁₁V₁ + Y₁₂V₂; I₂ = Y₂₁V₁ + Y₂₂V₂ Parallel two-ports with common port voltages: add Y
Transmission T = ABCD V₁ = AV₂ + B(−I₂); I₁ = CV₂ + D(−I₂) Cascade: Ttotal = Tfirst Tsecond, in physical order
Scattering S b₁ = S₁₁a₁ + S₁₂a₂; b₂ = S₂₁a₁ + S₂₂a₂ Incident/reflected waves at specified reference impedances

In ABCD, A and D are dimensionless, B is in Ω and C in S. The current −I₂ leaves port 2, so it becomes the entering port-1 current of the next cascaded stage. Here T means voltage/current ABCD, not the different chain-scattering matrix that some RF texts also call T.

Matrix multiplication is valid for these cascade variables; multiplying Z matrices is not a cascade rule. See Michael Steer's two-port definitions and interconnections.

The factor two reflects the source's available incident wave; it does not mean an ideal through connection loses half its available power.
