16.23 How can a 100 pF capacitor look like 1 nF without changing the component?

Predict. An ideal small-signal voltage amplifier imposes V₂ = −9V₁, with zero output impedance and otherwise infinite input resistance. A 100 pF capacitor bridges its input and output. A source drives the input through 10 kΩ, and a separate 20 pF capacitance connects the input to reference. Predict the input loading, source-to-input bandwidth and the effect of changing the sign of gain.

1. Calculate the current before using the theorem. If V₁ changes by +10 mV, V₂ changes by −90 mV, so the bridge voltage changes by 100 mV, ten times the input change. If this occurs as a linear ramp over 1 µs, bridge current entering node 1 is 10 µA.

The same current would flow into a grounded 1 nF capacitor under that input ramp. This is a small-signal charge/current result; the physical capacitor remains 100 pF.

From §11.5, CM,in = 100 pF × [1 − (−9)] = 1 nF. The output equivalent is 111.1 pF, because its factor is 1 − 1/(−9), not ten. Input and output therefore do not generally see the same apparent capacitance.

2. Translate current loading into bandwidth. Including the separate input shunt gives 1.02 nF. With the prescribed constant gain, the original circuit's input KCL reduces exactly to:

The time constant is 10.2 µs and source-to-input −3 dB frequency is 15.60 kHz. With the output instead AC-grounded (Av = 0), the input sees 120 pF and the corner is 132.63 kHz. The bridge has not changed; the output motion makes the input driver supply more capacitive current. With fixed Av = −9, the source-to-output transfer has the same pole and nine times the magnitude, with inversion.

3. Change the gain, not the capacitor.

For Av = +2 the model's pole is +1.25 × 10⁶ s⁻¹, in the right half-plane. Do not report a stable bandwidth by taking the absolute value of negative capacitance. The active output source permits non-passive input behaviour; a positive output voltage gain larger than one does not simply multiply the input capacitance into a larger positive number.

Connection to power electronics. A transistor's gate–drain capacitance bridges two moving nodes. During an inverting common-source transition, the driver supplies charge associated with the gate and drain voltage difference. This motivates the Miller-charge discussion in §16.8. For switching design, use the device's nonlinear capacitances/gate-charge curves and the actual voltage trajectory; this fixed 100 pF linear-amplifier model is not a MOSFET switching-loss or plateau-duration prediction.

Analog Devices' amplifier chapter discusses Miller capacitance in transistor stages.

Change one thing: replace the bridge capacitor by a resistor and predict the input impedance; then replace −9 by a near-unity follower and explain why bootstrapping reduces input current. A real follower's finite bandwidth and phase shift limit the cancellation. Keep the actual loaded node-voltage gain distinct from a source-to-output gain measured through the 10 kΩ input resistance.

Gain choice. Keep the inverting model when the required node gain is −9. Include its 1 nF apparent input capacitance in the source-loading calculation. A near-unity follower reduces loading, but no longer performs the same signal function.

Use bootstrapping when following the input is acceptable. If inversion is mandatory and loading is excessive, revise the source or amplifier interface instead of counting a different gain as an equivalent solution.
