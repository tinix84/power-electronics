18.10 Exercise: two dividers and a buffer

Two dividers produce the same unloaded voltage. Which remains closer to that voltage under load, and what does that improvement cost?

This is an original public practice exercise. All component values describe teaching models. The numerical answers are on the separate solution page.

Circuit A and circuit B

The supply is ideal and constant at 12 V. All resistors are ideal and constant. Disconnect the load for the unloaded case. Use the same load resistance for both circuits.

  1. Calculate the unloaded output voltage of each circuit.
  2. Find the Thévenin resistance seen by each load.
  3. Calculate both output voltages for loads of 5 kΩ, 1 kΩ, 500 Ω, 50 Ω and 5 Ω.
  4. Compare each load with both source resistances.
  5. Calculate the unloaded supply current and total resistor loss.
  6. Calculate each divider's two resistor losses with a 50 Ω load.
  7. Find the minimum load resistance for at most 1% voltage reduction.
  8. Explain why the lower-resistance divider is still an imperfect voltage source.

Add an op-amp voltage follower

An operational amplifier (op-amp) can separate the reference input from the load-current path. Negative feedback connects its output to its inverting input.

The ideal follower draws no input current and holds its output at the reference voltage. Load current comes through the amplifier's supply connections. It does not pass through the reference divider.

For the calculation, assume that the follower can supply the required current from a 12 V supply. Use a 100 Ω load. Neglect input current, voltage offset and quiescent supply current.

  1. Calculate the divider voltage and load current.
  2. Calculate the divider loss and load power.
  3. Calculate the active stage's dissipation using a linear output-stage power balance.
  4. Calculate the total supply power, including the divider.
  5. Explain how a 40 mA output-current limit invalidates the ideal result.

A real buffer provides finite isolation. Input bias current still loads the reference. Output current, voltage swing, common-mode range and temperature limit its usable load range. Bandwidth and load capacitance affect settling and stability.

A buffer reduces direct load-current interaction with the reference. It does not provide galvanic isolation or remove shared supply and return impedances. A supply-derived reference still follows supply changes.

Compare an NPN emitter follower

A single NPN transistor can also provide current gain. Its collector draws most of the load current from the supply. Its base still draws current from the reference divider.

Use a constant current gain and a constant base-emitter drop . Assume forward-active operation. These values are model assumptions, not device specifications.

  1. Express base current in terms of load current.
  2. Include base current in the divider's Thévenin model.
  3. Calculate the base voltage, emitter voltage and load current for 100 Ω.
  4. Compare the result with the ideal op-amp follower.
  5. Explain why the transistor does not preserve a precise 6 V output.

Actual and current gain change with operating conditions. A bare emitter follower therefore provides approximate buffering, with a voltage shift and residual reference loading.

Analog Devices' emitter-follower laboratory explains the current gain and voltage shift. Its AN-581 discusses divider bias, input-current errors and supply coupling in op-amp circuits.
